# 100 款相机与实物照片更新

沿用 NiCam 原站点，目录扩展为恰好 100 款独立型号：原有 7 款数码机型及新增 93 款经典胶片相机。补充品牌含 Pentax、Minolta、Olympus、Kiev、Zenit、Ihagee、Polaroid。新品牌页面提供资料入口及相关机型，历史时间线尚待编写。

所有机型使用本地打包 WebP 实物照片，带作者、许可及 Commons 原始文件链接，不使用生成图或相机插画。照片逐张通过联系表检查，部分型号存在地区命名、配色或限量版本区别，具体说明见图片注记及 PHOTO-QA.md。仅调整尺寸和编码，未进行内容合成。每张照片保留其 CC BY、CC BY-SA、CC0 或公有领域条款；公开的 photo-credits.json 保留署名及来源。

新增型号来源于 camera-gear-database 的 CC0 数据（固定提交 05f34baf69747263e278295179f7687d630cb51d），结合逐张照片许可清单筛选。没有复制摄影媒体评测或参数库。新增93款为待核验档案，不代表已完成官方参数审计。未知年份、有效像素与尺寸为 null；胶片不适用数字有效像素。二手资料的年份、画幅尚需官方逐项核验。原有两条完整官方核验记录保留。

来源仓库明确提示部分自动推断可能出错，因此本次剔除发现的数码/胶片误分类、照片错配、复杂许可及分辨率不足条目。未来完善时应以官方博物馆、说明书为依据，逐项补齐参数及证据，不能仅凭图像推断规格。

目录默认加载24款，继续加载每批24款；切换筛选或排序时重置。未知年份不参与年代过滤且排序置后，照片延迟加载，大图优先加载。所有图片随构建托管，浏览者无需连接外部图片域名。

复现：下载固定来源仓库，用 scripts/import-photo-catalog.py 导入（依赖 Pillow，且需要已下载的原始数码照片），可选 scripts/upgrade-photo-resolution.py 获取更清晰原图；修改后运行 npm test / npm run build。源候选、照片证据及最终元数据随代码保存。

自动化检查涵盖100款唯一记录与逐款本地图片、署名、许可、源链接及最低尺寸；计算与对比回归测试仍保留。浏览器/Safari实机验证仍受原环境工具缺失限制。
