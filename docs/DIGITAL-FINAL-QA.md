# 数码目录最终检查

检查日期：2026-11-06。此记录区分结构检查、来源抽查与照片人工查看；任何一项都不能独立证明全部规格事实及全部图片许可。未进行浏览器交互检查。

## 来源与主要参数

逐批检查 Canon、Nikon、Sony、Fujifilm 共80款的分组与主要参数覆盖，结合本地保存的厂家页面检查关键条件。不以参数数量代替完整性：Canon RP 曾因官网空标题漏掉整个自动对焦及显示屏部分，已从已读取的官方规格页补回14行，并将快门单独分组。其余四批主要技术域均有实际内容；部分旧款佳能视频事实归在图像文件分组中。

关键条件抽查：

- Canon EOS R50：欧洲规格页将电子前帘范围称为 Mechanical，HDR PQ视频写为8位。另行读取[佳能官方说明书](https://cam.start.canon/en/C011/manual/html/UG-11_Reference_0090.html)，确认电子前帘为30–1/4000秒、电子快门为30–1/8000秒，均支持B门；说明书明确列出10 bits (HDR PQ)。数据已按说明书修正，并在视频行说明两个官方来源不一致。弱光AF的f/1.2、中央点、单次AF及温度/ISO条件已保留。
- Nikon Z8/Z9：规格页最高120fps不能理解为全像素RAW；数据保留JPEG、小尺寸约1100万像素条件，C60保留DX裁切。Zf 30fps保留JPEG Normal及大尺寸限制，14fps与RAW约11fps另作区分。规格页本身没有完整JPEG条件，数据使用补充说明书条件，检查不宣称仅凭产品页证明这些条件。
- Sony A7 IV：缓存官方帮助指南说明无压缩及无损压缩RAW会降低连拍速度；数据10fps行已保留该限制。A1 30fps行另标压缩RAW/JPEG与镜头要求，无压缩/无损压缩RAW最高20fps。
- Fujifilm X-T5：保存的厂家规格页明确20fps电子快门使用1.29倍裁切，数据保留；7级防抖保留CIPA、俯仰/偏摆及XF35mmF1.4 R测试镜头。360Mbps视频记录的V60卡要求亦保留。X100VI机械镜间快门与电子快门范围分列。

内容有中文标签及厂家英文技术术语，长视频格式/连拍缓存行仍含英文与多种条件，适合详细参数查阅；不宣称完成逐句中文重写或逐行独立事实复核。

## 照片人工检查

已实际查看五品牌批次的全部100张本地照片联系表，发现Canon EOS 6D Mark II、EOS R5 Mark II两张仅为包装盒，Nikon Z5为水滴样片，已由负责人更换并重新下载；之后从最新文件生成独立联系表实际打开复查，三张均为正确机身且型号铭牌清楚可见。最终全部100张均为相机实物照片，未留已知错图或包装盒。其余97张为相机实物，Leica Q2已是正确的新机身照片。另单独打开Canon250D、Nikon D750、Sony A9 II及Fujifilm X100VI复查：前三款为真实机身，但侧面/阴影/前面铭牌不能独立证明所有后缀，须结合精确型号源页；X100VI为一台机身的背面及向下翻转的屏幕，上方铭牌清楚显示VI。Fujifilm X-T30照片前景为目标机型，背景另有一台X-T30 II。

100张文件下载完成后执行 `python scripts/validate-digital-batches.py`：5批各20款、共100个唯一数码机型，结构检查通过。最少参数行数/分组：Canon67/15、Nikon51/16、Sony35/13、Fujifilm33/8、Other37/8；每行HTTPS来源、照片元数据/文件尺寸、重复与禁止字段均通过程序检查。许可来源与署名的独立抽查另见PHOTO-FINAL-AUDIT.md；没有宣称逐张独立复核全部100张许可。
