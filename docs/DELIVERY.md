## 运行和发布准备

执行 `npm ci`、`npm test`、`npm run build`；在普通本地开发环境可 `npm run dev`。静态产物位于 dist，路由使用 hash。受管理环境中应按 Sites 的受支持预览流程启动，而非自行启动服务器。

正式部署前恢复 Sites 打包及预览能力，完成浏览器检查；通过原生工具获得真实站点 ID 后配置 static.directory=dist，再同步来源和打包。公开发布仍须用户确认。
